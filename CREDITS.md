## Original Clayium

This project is an independent Minecraft 1.21.1 / NeoForge port and redesign of
the original Clayium mod for Minecraft 1.7.10.

- Original name: Clayium
- Original author: deb_rk (`_ForgeUser24077589`)
- Original distribution page: <https://www.curseforge.com/minecraft/mc-mods/clayium>
- Original reference file: `Clayium 0.4.6.36 (hotfix3)` for Minecraft 1.7.10
- License policy for this project: CC BY 4.0

The port changes the registry model, recipe system, storage, synchronization,
capability integration, GUI architecture, and other implementation details for
the current Minecraft and NeoForge environment.
